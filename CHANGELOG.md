# Changelog

What changed in each release of this plugin. Versions follow [semantic versioning](https://semver.org).

## [2.0.0]

- The plugin has a repository and releases of its own, apart from Melodex. It's the same plugin Melodex 1.x shipped,
  and its image keeps its name, `ghcr.io/dextrd/melodex-retriever-soulseek`. Its versions carry on from Melodex's, and from now on go their
  own way.
